
# FreeCAD - A Model You Can Change Later

[![Open FreeCAD](https://img.shields.io/badge/Open-FreeCAD-ca8a04?style=for-the-badge&logoColor=white)](https://susanjacksonk22.github.io/.github/FreeCAD)

## About FreeCAD

FreeCAD builds 3D models you design: a part, a bracket, a simple shape you can measure. It is a modeler for your own work. It does not include a catalog of commercial products to reprint, and a mesh you do not have rights to is not a starting file you should import and call your design.

A parametric model keeps the sizes editable. If you change a width, the sketch can update. That only helps if you save the FreeCAD file. An exported STL is a frozen shape for a printer or a viewer. Keep the FreeCAD file if you will revise the part.

Start with one solid you can measure. A full assembly is easier after a single part opens and exports cleanly.

## How to Use FreeCAD

1. Create a new document and sketch a shape with dimensions you can check.  
2. Turn that sketch into a solid and look at the size.  
3. Save the FreeCAD file before you export anything.  
4. Export an STL or STEP under a new name if a printer or another program needs it.  
5. Open the export only to confirm it. Do your next edit in the FreeCAD file.

---

## Features Included in FreeCAD

- Sketches with dimensions for parts you design  
- Solids built from those sketches  
- A saved project file you can reopen  
- Export to formats other tools accept  
- A way to change a dimension later if the model is still parametric  
- One part at a time before an assembly  
- Undo while the document is open  
- The export kept separate from the source file

---

## Troubleshooting

- The export is empty? You exported the wrong body or the solid was not created. Check the model, then export again.  
- The file will not reopen? You may have opened the STL. Open the FreeCAD document.  
- A downloaded mesh will not become a clean sketch? If you do not have rights to that model, do not import it. Draw the part you need.
